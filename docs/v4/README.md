# v4：要教什么，模型才能迁移到没见过的结构（监督对照研究）

v2 发现：只学动作的模型在已见结构族的新布局上成绩很好，到留出结构族上明显下降，加几何监督（AG）也补不上。v4 在同一个底座（Qwen3.5-35B-A3B）、同一套 v2 协议下，再比较三种监督，每组 3 个种子，共 9 次训练：

| 组 | 教什么 | 训练数据 | 曝光次数 |
|---|---|---|---|
| A_cons | 走一步会发生什么 | 动作 15000（同种子与 A_base 顺序相同）+ `consequence_v4`：给一个候选动作，先写出每个目标移动后的高度占比、离画框最近的边距、3×3 采样点里被挡住和落在目标上的个数，再判断五项约束 | 后果样本数按 token 数与 AG 对齐 |
| A_geomact | 动作由几何推出来 | `geomact_v4`：提示词与 V0 完全相同，答案先写场景几何，换行再写动作；题目顺序与 A_base 相同（同种子下一个是另一个的前缀） | 样本数按 token 数与 AG 对齐 |
| A_nextview | 想象移动后的画面 | 动作 15000 + `nextview_v4`：给一个合法动作，写出移动后每个物体在画面里的边框 [左, 上, 右, 下]、深度和被挡住的采样点数（由 Locus 测得） | 画面样本数按 token 数与 AG 对齐 |

对照组直接用 v2 已跑完的 A_base、AG、A_compute（同底座、同种子、同协议），v4 不重跑。`configs/v4/AG.yaml` 只用来定义"与 AG 相同的训练量"，不训练。

模型、LoRA 位置和秩、优化器、有效批量 64、微批 1、损失、检查点和贪心解码，全部与 v2 相同（`tests/test_v4.py` 检查了这一点）。A_geomact 的答案先输出几何、后输出动作，冻结评分器读取的是最后一个 JSON，已核对能正确读出动作。它的训练答案估计最长约 400 token，V0 和验证集的生成上限从 512 提到 1024（运行前写定，只对这一组），以免物体多的场景还没写到动作就被截断；其他组只输出动作，不受影响。

## 数据

增量包 `locus-bundle-v1.7.0-addon-v4.tar`（183 MB），sha256 `5ad0a15b526e4d1f9778914e93db086619f3a0df19ab5dcbd918a03bb57a5914`，由基准方单独传过去。里面只有训练和验证用的三种数据，没有图片、场景、动作表或测试文件；所用图片都在原数据包里。

| | 训练集 | 验证集 |
|---|---:|---:|
| consequence_v4 | 29,400 条（每题 6 个动作：2 个可行、1 个非法终点、3 个违反约束，优先选离可行只差一步的） | 2,330 条 |
| geomact_v4 | 5,053 条（每题一条，与 action_sft 逐条对齐） | 400 条 |
| nextview_v4 | 20,212 条（每题 4 个合法动作：1 个可行、3 个违反约束） | 1,600 条 |

动作只按 `sha256(root_id|v4|action)` 的固定顺序挑选，与任何模型的结果无关。后果样本和画面样本对同一动作给出的目标高度，在 24,213 个共同组合上全部一致（最大差 0.01，来自四舍五入）。

## 一条命令跑完

```bash
export LOCUS_ROOT=/共享盘/项目目录
```

```bash
NODES=$LOCUS_ROOT/work/v4/nodes.txt ADDON_TAR=$LOCUS_ROOT/data/locus-bundle-v1.7.0-addon-v4.tar ADDON_SHA256=5ad0a15b526e4d1f9778914e93db086619f3a0df19ab5dcbd918a03bb57a5914 nohup scripts/run_all_v4.sh > /dev/null 2>&1 &
```

步骤和 v3_gemma 相同（见 [v3_gemma 说明](../v3_gemma/README.md) 的步骤表），区别是：

- 底座用 v2 已下载的 Qwen3.5-35B-A3B，不需要下载新权重；
- `setup` 会先核对并解压增量包；
- 三组的训练量都要先标定（v3_gemma 只有 A_compute 需要）；
- 测试题数为 (3 组 × 3 种子 + B0) × 600 = 6000 条 test_V0 答案；B0 与 v2 的 B0 是同一个模型，可用来核对推理结果是否一致；
- C1、C2 也会对 9 个新终点各跑一遍，用来看后果训练或几何训练是否改变了单独判断动作的能力。注意 A_cons 训练过与 C2 相近的格式，C2 对它不再是格式外的考查。

进度看 `$LOCUS_ROOT/work/v4/run_all.log`，训练进度看 `LCAM_ROUND=v4 launch/status.sh`。跑完把 `work/v4/locus-v4-results-<日期>.tar` 和同名 `.sha256` 发回基准方打分。

## 判定标准（运行前写定）

每组和 A_compute（同训练量、只学动作）比较，主指标是留出结构族（test_geometry）上的成功率。

- **有效**：3 个种子的均值比 A_compute 高至少 5 个点，且按题重抽样的 95% 区间不含 0。
- **同时报告**：test_id 和 test_composition（看是否以牺牲分布内为代价）、F13、主测试总分、几何路线、C1、C2。
- 不因为某一组结果好就追加训练或调参。
