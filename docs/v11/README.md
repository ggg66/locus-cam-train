# v11：学出来的决策为什么不迁移，什么能让它迁移

前面的结论有两条：
- 学出来的决策绑定训练结构。给模型正确几何，它在留出结构上也不用：镜像不镜像，成功率一样。
- 从随机场景学读几何、决策交给固定求解器，留出族从 34.8% 升到 54.7%（v10）。

v11 把这两件事拆开，检验三个反直觉的假设：
1. 训练数据多样了，学出来的决策仍然不迁移；同一份数据拿去学几何，却能迁移（A_rand 对 G_rand_r）。
2. 先写几何再决策的模型，即使在多样的结构上训练，到留出结构上仍然不跟着给定的几何走（GA_rand 的镜像测试）。
3. 不给图像、只给几何数字来学决策，决策反而能迁移：图像让模型认出场景、套用记住的动作，拿掉图像就拿掉了这条捷径（D_fam、D_rand）。

另外，随机的 10 种结构对设计的 10 个训练族（G_k10 对 G_fam），检验问题出在结构的数量，还是出在人为设计的场景本身。

## 实验

底座、协议与 v2 完全相同：模型、LoRA、优化器、有效批量 64、微批 1、损失、检查点、贪心解码。由 `tests/test_v11.py` 检查。每组 3 个种子，共 18 次训练，每次训练只有一种数据源。

| 组 | 训练数据 | 曝光 |
|---|---|---|
| `A_rand` | `action_rand_v11`：5,053 个随机场景，V0 题面 → 动作。标签规则同 `action_sft`（有余量的可行动作里位移最小，再按 r,u,b 字典序） | 15,000（同 Action） |
| `GA_rand` | `geomact_rand_v11`：同样的场景，V0 题面 → 几何、换行、动作（`geomact_v4` 格式），场景顺序与 A_rand 相同 | 19,072（同 v4 Geometry→Action） |
| `G_rand_r` | `geometry_randr_v11`：同样的场景，只学几何（`geometry_sft_v2` 格式） | 15,000 |
| `G_k10` | `geometry_randk10_v11`：10 种固定的随机结构，每种结构有很多布局，共 5,053 个场景，只学几何 | 15,000 |
| `D_fam` | `blind_fam_v11`：10 个训练族的 5,053 个场景。两张图换成空白画面，题面说明"本条件不提供图像"，并写入场景几何（`geometry_sft_v2` 的数字，隐藏字段取缺省值）→ `action_sft` 的标签 | 15,000 |
| `D_rand` | `blind_rand_v11`：A_rand 的 5,053 个随机场景，其余同 D_fam → `action_rand_v11` 的标签 | 15,000 |

**数据来源**：基准仓库的 `generator/random_v11.py` 生成场景，`training_exports/export_v11.py` 导出记录。
- **随机场景**（A_rand、GA_rand、G_rand_r、D_rand 共用）：沿用 v10 的随机布局。每个场景都执行全部 120 个候选视角，并通过训练族用的保留规则 R1–R6：
  - 零动作不成功；
  - 可行动作 4–60 个；
  - 至少一个有余量的可行动作；
  - 可行动作不孤立；
  - Locus 与重算一致；
  - 观察副本一致。

  v10 的 5,053 个场景里有 1,189 个通过，其余由新生成的场景补足，按编号取前 5,053 个。
- **10 种结构**：每种结构是一个固定的 v10 随机布局。每个场景在它的基础上做三种变化：
  - 以相机为中心整体缩放 0.8–1.2 倍，每个物体再移动最多 0.25 m；
  - 盒子各边缩放 0.85–1.15 倍；
  - 相机移动最多 0.3 m，并重抽朝向、焦距、尺寸目标、整体旋转和墙的位置。

  接收规则与 v10 的 G_rand 相同。
- **几何的写法**：蒙眼组题面里的几何文字，训练和测试都由同一个函数从数字生成，写法同 S 条件（`run_mllm.s_text`）。
- **名词与来源**：物体名只用训练族的名词，不读任何测试场景。

| 组 | 题目 | 新 token 数 |

## 打分（运行前写定）

在基准方完成。
- **成功**：动作在记录的可行集里；无效或未完成的答案算失败。
- **区间**：按场景重抽样（先对 3 个种子取平均），10,000 次，95% 百分位。
- **划分**：主要看留出族，同时报告已见族、留出组合、总分和逐个留出族。

**1. 同样的随机场景，学决策对学几何（A_rand）**
- 主指标：留出族上 A_rand − G_rand_r。另报 A_rand − Action（v2 A_base，29.8%）。
- 支持假设 1：A_rand − G_rand_r 的区间整体在 0 以下。
- 削弱假设 1：区间包含 0 或在 0 以上，说明结构多样了，学决策本身就够了。

**2. 决策跟不跟着几何走（GA_rand）**
- 主指标：留出族上，给真实几何减给镜像几何的成功率差；以及在真实可行集与镜像可行集不相交的题里，动作落在镜像可行集的比例。
- 对照：v4 Geometry→Action 在留出族上是 20.7% 对 21.3%，落在镜像可行集的比例是 2.6%。
- 支持假设 2：成功率差的区间包含 0，且落在镜像可行集的比例不高于 10%。
- 削弱假设 2：在多样的结构上学过之后，决策会用上给定的几何。
- 同时报告：GA_rand 自己的动作；求解器作用在它写出的几何上；给真实几何时与求解器的差。

**3. 蒙眼学决策（D_fam、D_rand）**
- 主指标 a：留出族上，`test_blind_true` 的成功率减去求解器作用在同一份几何（隐藏字段取缺省值）上的成功率。
- 主指标 b：留出族上，`test_blind_grand_s<k>` 的成功率减去求解器作用在同一份 G_rand 预测几何上的成功率（v10 `route_v10.csv`，同一种子）。
- 主指标 c：留出族上，D_fam 的 `test_blind_true` 减去 GA_rand 的 `test_geomact_true`，看拿掉图像的效果。
- 支持假设 3：D_fam 的主指标 a 在留出族上与 0 差得不远（区间下限高于 −15 个点），并且远高于 GA_rand 和 v4 Geometry→Action 给真实几何时的成功率。
- 削弱假设 3：蒙眼学出的决策在留出族上仍然远低于求解器。

**4. 随机的 10 种结构对设计的 10 个族（G_k10）**
- 主指标：留出族上 G_k10 − G_fam（v10，34.8%）。
- 区间整体在 0 以上，说明问题不在结构数量，而在设计出来的场景族本身；区间包含 0，则只说明 10 种结构不够。

**5. 其余**：G_rand_r − G_rand（v10），即按保留规则筛选场景本身的影响；按留出族的成功率；几何组的逐字段误差。

## 一条命令跑完

```bash
export LOCUS_ROOT=/共享盘/项目目录
```

```bash
NODES=$LOCUS_ROOT/work/v11/nodes.txt ADDON_TAR=$LOCUS_ROOT/data/locus-bundle-v1.7.0-addon-v11.tar ADDON_SHA256=<服务器说明里的 sha256> nohup scripts/run_v11.sh > /dev/null 2>&1 &
```

- 数据包要用 v10 跑过的那个，再加 v11 增量包。脚本会核对 sha256、记录条数和每张图片。
- 虚拟环境用 v10 的。
- 步骤依次是：
  1. 核对环境、增量包和文件；
  2. 单元测试；
  3. 用真实处理器检查六种训练数据；
  4. 训练 18 次，每个节点一次跑一个；
  5. 测试；
  6. 打包。
- 中途停下，修好原因后运行同一条命令，已完成的步骤会跳过。
- 进度看 `work/v11/run_v11.log`。
