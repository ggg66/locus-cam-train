# v2 训练审计

本文件记录 v2 正式训练之前的门禁结果。第一部分是已经核实的事实，第二部分在服务器上跑完 `scripts/run_v2.sh` 各阶段后填写。

## 一、已经核实的事实（v1）

**1. v1 的损失怎么算。**
- v1 的 12 次训练用的是仓库里的 `scripts/train.py`（提交 acfc914，服务器上加了 8 卡数据并行）。
- 每张卡上，一个微批先用 Hugging Face 的 `out.loss` 求损失，也就是对这个微批里全部被学习的 token 取平均，再除以累积次数 4。
- 8 张卡的梯度先取平均，再做梯度裁剪和参数更新。
- 所以一个优化步的目标函数，是 32 个微批（每个 2 条样本）各自 token 平均值的平均。
- 后果：一条样本对目标函数的权重，取决于它和谁分在同一个微批。动作答案约 23 个被学习的 token，几何答案约 146 个；两者同在一个微批时，动作样本只占这个微批约 14% 的权重。
- 这属于设计选择，不是 bug：v1 配置没有规定要按样本平均。
- 按实际长度精确核算的结果，见第二部分的 `v1_weighting.json`。

**2. v1 的几何目标里留有看不到的真值。**
- 训练集 5053 条几何样本中，有 3589 条的部分字段只是不计损失，真值仍然写在答案文本里。
- 模型生成后面的字段时，前面的输入里已经有这些真值。
- 涉及的字段：人物中心高度和身高 2369 处，箱体中心高度和高度 4591 处，天花板 1055 处。没有任何水平位置被遮掉。

**3. v1 的同种子动作顺序不一致。** v1 的采样把两类样本混在一起后统一打乱，所以同一个种子下，B1 和 B2 的动作样本顺序不同。

**4. v1 各组的资源用量。**
- 可训练参数都是 76,677,120 个，LoRA 挂在 250 个线性层上。
- B1-secondary（20000 次动作）处理了 27.78M 个 token；B2-secondary（15000 次动作 + 5000 次几何）处理了 30.08M 个，多 8.3%。
- 墙上时间多约 16%，含模型加载时间。
- 资源口径选 token 数还是时间，结果会差约 8%，所以 v2 在训练前就定为"含补齐的 token 数"。

**5. B0 照抄示例。**
- V0 提示词最后一句是"只输出一个 JSON，例如 {"move_m": {"right": 0, "up": 0, "back": 0}}"。
- 未训练的模型在关闭推理时，600 道测试题里有 556 道原样输出这个零动作。
- v2 不改冻结的提示词，只在 dev 上加一组占位符版本做对照：`dev_V0` 与 `dev_V0_placeholder`。

**6. 批次里的样本会互相影响（2026-10-24 服务器门禁发现）。**
- 门禁 equiv 第一次没通过：张量范数最大差 9.8%，最小余弦 0.987。
- 服务器诊断确认，梯度在各卡之间的合并本身没有问题。让单卡按 8 卡的方式两两配对后再比较，目标函数差 5.6e-9，余弦 0.99992。
- 真正的原因是：同一条样本的损失，会随它和谁分在同一个微批而变。两条样本等长、不需要补齐时，结果和单独前向完全一致；长度不同时，被补齐的短样本损失平均变 4.7%，没被补齐的长样本平均变 3%，最多 16.9%。
- 可疑的位置是线性注意力或因果卷积对补齐位置的处理、MoE 路由、多模态位置编码，具体是哪一个还没有确认。
- v1 也是两两配对训练的，同样受影响。
- 这个影响在各组之间不对称：AG 里，动作样本常和更长的几何样本分在同一个微批，要补齐到几何样本的长度；A_base 里，动作样本之间长度相近。
- 所以 v2 改为每个微批只放 1 条样本，8 卡时每卡累积 8 次。这样不存在补齐，样本之间也不会互相影响。门禁 equiv 改为单卡累积 64 次对 8 卡累积 8 次，两边每条样本的前向完全相同，应当通过。
- 推理同样是批量生成。门禁 batchcheck 用 B0 在验证集上比较批量 1 和批量 8 的答案：解析出的动作不一致超过 1% 时，v2 的评测全部改用批量 1。v1 的答案是用批量 8 生成的。

## 二、v2 的处理与核验

**隐藏字段改用缺省值**（基准方 `training_exports/hidden_defaults.py`、`export_v2.py`）：
- 缺省值只用训练集里"看不到"的那部分样本的中位数来定：人物身高 1.70 米，站在地上；箱体高度 2.60 米，放在地上；房间高度 4.60 米。
- 验证集同类情况的中位数与这三个值完全相同。
- 训练集有 2437 条目标因此改变。另有 1152 条原本被遮掉，但真值恰好等于缺省值，文本不变。

**缺省值对几何路线的影响**（验证集 400 题，固定求解器，不用测试集）：

| 输入 | 求解器成功率 |
|---|---:|
| 真值几何 | 92.25% |
| 真值几何，看不到的字段换成缺省值 | 84.50% |
| 只换人物身高 | 89.25% |
| 只换箱体高度（全是遮挡物） | 87.50% |
| 只换天花板 | 92.25% |

所以，只看图能做到的几何路线上限比真值低约 8 个百分点。主要是看不见的遮挡物高度和被挡住的人物身高造成的。报告时，这个上限和真值上限要分开写。
